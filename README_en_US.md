## Features

- **Multi-platform Support**: Compatible with notes from Kindle, Apple Books, KOReader, WeReader, and more
- **Batch Import**: Import large quantities of notes to flomo at once
- **Custom Tags**: Add custom tags to imported notes for better organization
- **Content Editing**: Edit note content before importing
- **Local Storage**: All data is stored locally for privacy protection
- **Multiple Export Options**: Export notes as Markdown, CSV, and other formats

## How to Use

1. Download and install Send2flomo
2. Export notes from your reading device or app (HTML, TXT or JSON format)
3. Upload the notes file in Send2flomo
4. Configure flomo API and select the notes you want to import
5. Click the import button to complete the migration
